
# Iris Flower Classification

## 1. Project Overview
This project predicts the species of Iris flowers using Machine Learning.

## 2. Dataset
The Iris dataset contains 150 records and 4 input features.

Target column: species

## 3. Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Google Colab

## 4. Exploratory Data Analysis (EDA)
- Dataset analysis
- Missing value checking
- Species count graph
- Pair plot
- Feature visualization

## 5. Machine Learning Algorithms
1. K-Nearest Neighbors (KNN)
2. Logistic Regression
3. Decision Tree

## 6. Model Evaluation
- Accuracy
- Precision
- Recall
- Confusion Matrix

## 7. Model Prediction
The trained model predicts the Iris flower species.

## 8. Model Saving
The best trained model is saved as:
iris_best_model.pkl

## 9. Project Files
- Iris_Classification.ipynb

- README.md

## 10. Conclusion
This project demonstrates how Machine Learning
can classify Iris flowers using Python.
